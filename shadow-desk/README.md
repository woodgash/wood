## 為什麼還要改腳本

這頁是電腦上的腳本每天 8:05 / 20:05 自動重新產生並上傳的。
只改線上頁面，下一次自動更新就會被蓋回舊頁首。
要永久生效，把 `brand-snippet.html` 裡的三段套進產生 HTML 的那支腳本：

| 段落 | 貼哪裡 |
| --- | --- |
| STYLE | `<style>` 裡，`.head h1{...}` 那行後面 |
| HEADER | 取代 `<header class="head"><h1>影子模式戰情板</h1>` 這一行 |
| title | `<title>影子模式戰情板</title>` → `<title>Shadow Desk</title>` |

`badge`（只記錄，不下單）與 `stamp`（三個市場的時間）維持原樣，不用動。

## 設計說明

- logo 是內嵌 SVG，沒有外部圖檔，跟著頁面走，深淺色主題都吃得住。
- 漸層 `#FFC98F → #F2955F → #D9674A`，跟頁面既有的 `--accent` 暖色調同一家族。
- 墨鏡延續舊圖示的識別，臉是圓的所以縮到 28px 也還認得出來。
- 標題字用頁面已載入的 IBM Plex Mono，不必多載字型。
