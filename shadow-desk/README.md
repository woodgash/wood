# Shadow Desk — 手機戰情板品牌改版

原本：`影子模式戰情板` + 🕶️ 圖示
現在：`Shadow Desk`（副標保留「影子模式戰情板」）+ 橘色吉祥物 logo，桌面圖示 😎

線上頁面已經是新的：https://claude.ai/code/artifact/96e53239-3303-44e6-ad36-c84cb66a9292
（同一個網址，手機捷徑不用重加。）

## 永久生效：跑一次就好

戰情板頁面是電腦上的腳本每天 8:05 / 20:05 自動重新產生的，只改線上頁面會被下一次自動更新蓋掉。
`patch_shadow_desk.py` 會直接把改動寫進那支腳本裡：

1. 把 `patch_shadow_desk.py` 和 `套用新logo.bat` 兩個檔案，放到有 `報表.html` / `看報表.bat` 的那個資料夾。
2. 雙擊 `套用新logo.bat`（也可以把別的資料夾拖到它上面）。
3. 看到「改好 N 個檔案」就成了。重跑一次報表腳本，或等下一次自動更新。

想先看會動到什麼，不真的改：

```
python patch_shadow_desk.py --dry-run
```

它會做的事：

- `<title>影子模式戰情板</title>` → `<title>Shadow Desk</title>`（手機捷徑的名字讀這個）
- `<h1>影子模式戰情板</h1>` → 吉祥物 logo 區塊（自帶 `<style>`，不必去動原本那一大段 CSS）
- 每個改到的檔案先備份成 `檔名.bak-年月日-時分秒`
- 重複執行不會重複貼；`.py` 樣板若是 f-string（CSS 寫成 `{{ }}`），插入的 CSS 會自動跟著加倍
- 檔案是 UTF-8 或 Big5(cp950) 都讀得動，寫回去用原本的編碼

如果它印出「有提到影子模式戰情板但找不到錨點」的檔案清單，代表那支腳本的寫法跟預期不同 —— 把那個檔案貼給 Claude，直接幫你改。

要手動貼的話，內容在 `brand-snippet.html`。

## 設計說明

- logo 是內嵌 SVG，沒有外部圖檔，跟著頁面走，深淺色主題都吃得住。
- 漸層 `#FFC98F → #F2955F → #D9674A`，跟頁面既有的暖色 accent 同一家族。
- 墨鏡延續舊圖示的識別，臉是圓的所以縮到 28px 也還認得出來。
- 標題字用頁面已載入的 IBM Plex Mono，不必多載字型。
- 屬性用單引號、CSS 字體名不加引號，避免貼進 Python 字串時撞到雙引號。

## 驗證過的情境

`patch_shadow_desk.py` 對這幾種生成器寫法都實測過（改完後腳本仍可正常執行、產出的 HTML 正確）：
f-string 樣板（`{{ }}`）、一般三引號字串、純 `.html` 樣板、cp950 編碼的 `.py`、以及重複執行。
